OVERVIEW
Este caso de uso define o modelo de dados para agendamento de eventos.
Este caso de uso define o funcionamento do endpoint POST v1/event/schedule

DATA MODEL:
event_schedule: Armazena dados do evento.
id (id não sequencial UUID v7)
application_client_id (obrigatório) id da aplicação dona do evento (FK com id da tabela application_client)
title (obrigatório) título do evento
description (obrigatório) descrição do evento
organized_by (obrigatório) Nome do organizador do evento
location (obrigatório) Posição geográfica de onde o evento vai ocorrer
start_at (obrigatório) Data e hora UTC de quando o evento irá começar
end_at (obrigatório) Data e hora UTC de quando o evento irá terminar
created_at (obrigatório) Quando o registro foi criado
updated_at (obrigatório) Quando o registro foi alterado
deleted_at (obrigatório) Quando o evento foi deletado/cancelado pelo owner

EXECUÇÃO:

- Crie os modelos de dados em domain/entities
- Crie as entidades mapeadas em infra/persistence/jpaentity
- Crie as interfaces para as novas entidades em infra/persistence/jparepository
- Crie um port EventScheduleGateway para ser usado em casos de uso.
- Crie o record CreateEventInput.java contendo, title, description, organizedBy, location, startAt e endAt
- Implemente caso de uso criar evento. Deve receber application_client_id e CreateEventInput. Deve validar os campos obrigatórios, caso inválido, deve lançar a exceção ValidationException e caso válido, chamar o EventRepositoryGateway para a persistência e retornar o EventSchedule com todos os dados preenchidos.
- Crie um Controller EventController (/v1/event/schedule). Crie o método POST e acione o caso de uso.
