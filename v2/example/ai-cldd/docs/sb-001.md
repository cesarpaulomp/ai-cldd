SYSTEM OVERVIEW
Este documento define qual biblioteca deve ser utilizada para aplicar alterações no banco de dados, em qual local devem ser mantidos os scripts SQL e o master changelog, e quais convenções de nomenclatura devem ser seguidas. Complementa o SB-000.

TECHNOLOGIES

- Liquibase
  Maven: org.liquibase:liquibase-core

CONSTRAINTS AND HARD RULES

- O master changelog DEVE ser um arquivo XML localizado em src/main/resources/liquibase/db.changelog-master.xml.
- Arquivos para alteração/criação de tabelas devem ter o prefixo ddl-{tema}-{sequencia}.sql
  Ex: ddl-event-001.sql
- Arquivos que fazem alteração nos dados devem ter o prefixo dml-{tema}-{sequencia}.sql
  Ex: dml-event-001.sql
- {tema} deve ser o nome da entidade principal afetada, em minúsculas e sem espaços.
- {sequencia} deve ser um número com 3 dígitos, começando em 001 e incrementando por tema.

PROJECT STRUCTURE

- src/main/resources/liquibase/db.changelog-master.xml
  Responsabilidade: master changelog do Liquibase.

- src/main/resources/liquibase/scripts
  Responsabilidade: manter os arquivos .sql com as alterações no banco de dados (DDL e DML), seguindo as convenções de nomenclatura definidas neste documento.
