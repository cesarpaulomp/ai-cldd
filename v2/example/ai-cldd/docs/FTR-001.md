OVERVIEW
Este caso de uso define o modelo de dados para agendamento de eventos, cadastro de aplicações clientes e log de eventos da plataforma.

DATA MODEL:
event_log
id (id não sequencial)
application_client_id (Obrigatório)
event_name (Obrigatório)
body (Obrigatório)
created_at (obrigatório) Quando o evento foi criado

application_client
id (id não sequencial)
name (Obrigatório) Nome da aplicacao cliente
client_secret - Hash para autorização do cliente no uso dos endpoints
created_at (obrigatório) Quando o evento foi criado
updated_at (obrigatório) Quando o registro foi alterado

event_shechedule: Armazena dados do evento.
id (id não sequencial)
application_client_id (obrigatório) id da aplicação dona do evento (FK com id da tabela application_client)
title (obrigatório) título do evento
description (obrigatório) descrição do evento
organized_by (obrigatório) Nome do organizador do evento
location (obrigatório) Posição geográfica de onde o evento vai ocorrer
start_at (obrigatório) Data e hora UTC de quando o evento irá começar
end_at (obrigatório) Data e hora UTC de quando o evento irá terminar
created_at (obrigatório) Quando o registro foi criado
updated_at (obrigatório) Quando o registro foi alterado
deleted_at (obrigatório) Quando o evento foi deletado/cancelado pelo owner
